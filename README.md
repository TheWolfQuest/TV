# WolfTV 2.0

One consolidated GitHub Pages app based on the existing TV repository.

## Included
- No poster view or poster placeholders
- No Cost column
- Direct editing inside table cells; no Edit button
- Combined Watched format such as `S2 E4`
- Clickable Next column that advances episode progress
- Profiles: Keith, Debby, Sara, Kevin, John and Glenn
- Shared catalog with separate profile progress, ratings, favorites and notes
- Instant search and filters
- Dashboard and timeline
- Backup/restore and CSV import/export
- Responsive PC, tablet and phone layout

Upload all files to the root of the GitHub `TV` repository and replace the existing files.
